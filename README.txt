JAI MARUTHI POLYMERS WEBSITE
============================


This folder contains a ready-to-publish static website.

MAIN FILES
- index.html
- styles.css
- script.js
- assets/ (company images extracted from your brochure + brochure PDF)

PUBLISH FREE WITH GITHUB PAGES
1. Create/sign in to GitHub.
2. Create a PUBLIC repository, e.g. jai-maruthi-polymers.
3. Upload everything INSIDE this folder, keeping the assets folder.
4. Open repository Settings > Pages.
5. Under Build and deployment choose "Deploy from a branch".
6. Select main branch and /(root), then Save.
7. Wait for the temporary github.io website URL to appear.
8. Only after the temporary website works, add www.jaimaruthipolymers.com as the custom domain.
9. Then update DNS at GoDaddy to point the domain to GitHub Pages.
